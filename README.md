# BELUZ Cronograma para Windows

Instalador oficial gratuito para Windows 10/11, 64 bits.

Baixe o arquivo .exe na seção Releases, abra, clique em Instalar e depois em Abrir BELUZ. Entre com sua conta do site. Requer internet e Microsoft WebView2.

O aplicativo utiliza o site oficial https://beluz-cronograma-dxpk.onrender.com e os mesmos dados e permissões. Código-fonte mantido em repositório privado. O instalador não possui assinatura comercial de editor.
